# 视频转码平台 — 快速启动指南

> 阶段 4：mock 任务调度闭环（2026-07-28）

## 前置依赖

- ZooKeeper 运行中（`127.0.0.1:2181`）
- 项目已编译（`cmake --build build -j$(nproc)`）

## 一、一键启动 / 停止

### 启动（6 个服务）

```bash
#!/bin/bash
cd /home/wevix/muduo_im

# 按依赖顺序启动（WorkerManager → ResultCollector → Scheduler → Worker → JobService）
./bin/worker_manager   -i video_platform/conf/worker_manager.conf &
./bin/result_collector -i video_platform/conf/result_collector.conf &
./bin/scheduler_service -i video_platform/conf/scheduler.conf &
./bin/transcode_worker -i video_platform/conf/transcode_worker_9004.conf &
./bin/transcode_worker -i video_platform/conf/transcode_worker_9010.conf &
./bin/transcode_worker -i video_platform/conf/transcode_worker_9011.conf &
sleep 2
./bin/job_service      -i video_platform/conf/job_service.conf &
sleep 1
echo "All services started."
```

### 停止

```bash
pkill -f "worker_manager|result_collector|scheduler_service|transcode_worker|job_service"
# 确认
ps aux | grep -E "worker_manager|result_collector|scheduler_service|transcode_worker|job_service" | grep -v grep
```

## 三、查询任务

```bash
./bin/job_client -i video_platform/conf/job_client.conf --query job_1785232756714_000000_6155
```

输出示例：

```
│  Resolution:  720p
│  Shard count: 3
│
│  Shards (3):
│    ○ [0] job_xxx_shard_0
│       status=ASSIGNED  worker=worker_001
│    ✓ [1] job_xxx_shard_1
│       status=SUCCESS  worker=worker_002
│    ○ [2] job_xxx_shard_2
│       status=RUNNING  worker=worker_003
│
│  Progress: [=======             ] 1/3 (33%)
└──────────────────────────────────
```

状态标记：✓=SUCCESS  ○=运行中/等待中  ✗=FAILED

### 轮询查询（自动刷新直到终态）

```bash
./bin/job_client -i video_platform/conf/job_client.conf --query job_1785222685860_000000_9648 --watch
```

每 2 秒刷新，job 到达终态（SUCCESS / FAILED / CANCELED）时自动停止。

### 预期时间线

| 时间 | 状态 | 说明 |
|------|------|------|
| 提交后 0-1s | PENDING → SCHEDULING | Scheduler 接受到切分完成 |
| 提交后 2-3s | RUNNING | 后台调度循环分配 Worker |
| 提交后 7-8s | SUCCESS | 3 个 Worker 各执行 5s mock，全部完成 |

默认配置：60s 视频切 3 个 shard，每个 shard 执行 5 秒（mock）。

```bash
grep "SchedulerService\|SchedulingLoop" program_log/2026-07-28-log.txt | tail -20

grep "ResultCollector" program_log/2026-07-28-log.txt | tail -20
```

### 关键日志 checklist

```bash
LOG="program_log/$(date +%Y-%m-%d)-log.txt"

echo "1. Job 创建:";    grep "created job_id" $LOG | tail -1
echo "2. Scheduler 切分:"; grep "splitting into" $LOG | tail -1
echo "3. Shard 创建:";  grep "created shard" $LOG | tail -3
echo "4. Worker 分配:"; grep "assigned shard" $LOG | tail -3

```

## 六、Mock 配置参数

| 配置键 | 所在文件 | 默认值 | 说明 |
|--------|---------|--------|------|
| `mock_job_duration_sec` | scheduler.conf | 60 | mock 视频总时长（秒） |
| `mock_shard_duration_sec` | scheduler.conf | 20 | 每 shard 视频时长，60/20=3 shard |
| `mock_execution_time_ms` | worker conf | 5000 | 每个 shard 的 mock 执行耗时（毫秒） |

修改配置后重启对应服务即可生效。
